GitHub Co-Authors Generator

Adds an Add co-authors button to the merge box of GitHub pull requests.

GitHub account

The extension calls the GitHub API with your own account. Signed in, you get 5,000 requests per hour. Without signing in you share 60 per hour with everyone on your network.

Use a personal access token

Create a fine-grained token with read-only Pull requests and Contents access (Contents is only used for pull requests with more than 250 commits), or a classic token with no scopes (public repositories) or the repo scope (private repositories).

Who to credit

Bots and common service accounts are always skipped, and people already listed as co-authors in the description are not added twice.

Advanced: OAuth App for “Sign in with GitHub”

Sign-in uses GitHub’s device flow, which needs the client ID of an OAuth App. Register one with any homepage and callback URL (for example https://github.com) and tick Enable Device Flow. The client ID is not a secret.
